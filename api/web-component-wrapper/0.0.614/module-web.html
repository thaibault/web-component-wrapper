(inner) Web

Generic web component to render a content against instance-specific values.
Properties:
Name Type Description
applyRootBinding If determined itself as root declarative event and property bindings will be applied to itself.
content Content to render when changes happened.
determineRootBinding If checked this component determines if it is a root component (not wrapped by another web-component).
shadowDOM Configures if a shadow dom should be used during web-component instantiation. Can hold initialize configuration.
observedAttributes Attribute names to observe for changes.
controllableProperties A list of controllable property names.
eventToPropertyMapping Explicitly defined output events (a mapping of event names to a potential parameter to properties-transformer).
propertyAliases A mapping of property names to be treated as equal.
propertyTypes Configuration defining how to convert attributes into properties and reflect property changes back to attributes.
propertiesToReflectAsAttributes An Item, List, or Mapping of properties to reflect as attributes.
renderProperties List of known render properties.
cloneSlots Indicates whether to clone slot before to transclude content into them. If a slot should be used multiple times (for example, when it works as a template node.) they should be copied to avoid unexpected mutations.
doRender Configures whether this component instance should evaluate its given body content.
evaluateSlots Indicates whether to evaluate slot content when before rendering them.
renderSlots Indicates whether determined slots should be rendered into root node.
trimSlots Ignore empty text nodes while applying slots.
renderUnsafe Defines default render behavior.
_name Name to access instance-evaluated content or used to derive default component name. This is also useful for logging.
_propertyAliasIndex Internal alias index to quickly match properties in both directions.
_propertiesToReflectAsAttributes A mapping of property names to set as attributes when they are set/updated. Uses a map to hold order and determine if a property exists in constant runtime.
renderState Holds data about currently running render state.
Properties
Name Type Description
promise Promise resolving when next rendering has been finished.
pending Indicates whether a rendering task is performing.
resolve Callback to trigger when rendering has been finished.
childComponentInstances List of direct child components (needed to wait for them to finish dom manipulation).
batchAttributeUpdates Indicates whether to directly update dom after each attribute mutation or to wait and batch mutations after current queue has been finished.
batchPropertyUpdates Indicates whether to directly update dom after each property mutation or to wait and batch mutations after current queue has been finished.
batchUpdates Indicates whether to directly perform a re-rendering after changes on properties have been made.
batchedAttributeUpdateRunning A boolean indicator to identify if an attribute update is currently batched.
batchedPropertyUpdateRunning A boolean indicator to identify if a property update is currently batched.
batchedUpdateRunning Indicates whether a batched render update is currently running.
parentInstance Parent component instance.
rootInstance Root component instance.
scope Render scope.
domNodeEventBindings Holds a mapping from nodes with registered event handlers mapped to their deregistration function.
domNodeTemplateCache Caches template compilation results.
externalProperties Holds currently evaluated or seen properties.
ignoreAttributeUpdateObservations Indicates whether attribute updates should be considered (usually only needed internally).
internalProperties Holds currently evaluated properties which are owned by this instance and should always be delegated.
outputEventNames Set of determined output event names.
instance Wrapped component instance.
isRoot Indicates whether their exists another web-derived component up the tree or not.
root Hosting dom node.
runDomConnectionAndRenderingInSameEventQueue Indicates whether we should render initial dom immediately after the component is connected to dom. Deactivating this allows wrapped components to detect their parents since their parent-connected callback will be called before the children's render method.
self Back-reference to this class.
slots Grabbed slots that where present in the connecting phase.
